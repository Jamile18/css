# Blog de Tecnologia

Projeto acadêmico desenvolvido em HTML e CSS para a construção e estilização de um formulário de inscrição.

## Sobre o projeto

O projeto apresenta um blog estruturado com HTML semântico e um formulário de inscrição estilizado utilizando CSS e Flexbox.

## Estilização aplicada

Foram utilizados:

* Container com largura máxima;
* `padding`;
* `background-color`;
* `display: flex`;
* `flex-direction: column`;
* `gap`;
* Estilização de `label`, `input` e `select`;
* `border`;
* `border-radius`;
* `font-size`;
* Botão com destaque visual;
* `cursor: pointer`;
* Efeito `button:hover`;
* Campos de nome e e-mail posicionados lado a lado com Flexbox;
* Layout responsivo para telas menores.
